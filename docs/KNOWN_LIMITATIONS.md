# 4.0 已知限制

- 没有购买或绑定独立域名。候选域名查询与名称碰撞初筛不等于可注册或商标清查，见DOMAINS.md。
- 用户明确未授权付费AI，生产模型未启用、无真实模型质量验收。只有接入、校验、参数确认、mock响应→真实本地计算流水线已测试；不能声称在线大模型已接通。
- 后台为新增第一方同意事件，无法恢复旧版流量或读取原生Sites Analytics历史。未使用PostHog、Clarity、录屏/热力图。拒绝同意、拦截器、不同设备和机器人会影响UV估计与漏斗，不等于真实人数全覆盖。
- 后台查询最多50,000事件，超限会标记部分结果；实时为15秒刷新，活跃窗口5分钟，不是WebSocket连接人数。当前无按自然访客/验收流量自动分离、留存分析或可靠抗机器人识别。
- ADMIN_EMAILS依赖Sites网关提供的可信登录身份，不可把同一后端直接部署到未经身份网关保护的平台。若迁移，必须增加等价OAuth/JWT验证，不能直接信任外部请求头。
- 当前依赖审计还有6项high（braces及其Vite构建链传递依赖），上游braces最新3.0.3仍在公告影响范围；没有虚称0漏洞。这条链处理开发者提供的构建glob，本产品没有将用户表格、问题或公网请求传入该链；生产bundle未发现这些依赖名。需持续关注上游修补，构建不可信仓库时不应复用此信任假设。其他已发现的Next/RSC、Vite、Wrangler、Miniflare、fflate问题已升级/覆盖解决。构建有框架source-map和大chunk警告，不影响已验收行为。
- 不含蜡烛、提琴、等高线、3D散点等后续高级图；没有为它们放置假按钮。已有误差棒是用户给定的对称半宽，不自动解释为置信区间。多图最多6个Y字段，相关矩阵最多20列。
- 不含任意用户表达式、LOESS、幂律/Logistic、鲁棒/加权/分段回归、非线性最小二乘、变点检测或自定义数学模型。指数拟合为对数线性、乘性误差假设。Cubic Spline / Savitzky–Golay仍只在可选Python API中。
- 金融年化期数、价格口径、行顺序、CAGR年数需用户确认。年化波动/CAGR是全列估计，派生列中重复展示；回撤为截至当前的历史最大回撤。跨币种、混合单位的业务口径不自动推断。
- 40MB文件限制，XLSX/CSV超百万数据行拒绝，尚未实现真正百万行增量解析、严格内存配额或SLA。ZIP目录大小/比例检查不能替代恶意归档完整隔离。
- 原始与派生数据只存浏览器内存；刷新丢失，取消Worker需重新导入。撤销/重做最近10步。JSON重放需要完全相同原文件指纹及工作表，不能跨文件迁移。
- 仍默认首行是表头，不猜测合并表头、跨列单位或Excel公式重算；只读取公式缓存，不执行宏。空/仅表头Sheet跳过。
- 缺失值不参与对应绘图并提示，原数据保留；类别图求和、热力图网格均值有标注。极值包络降采样用于显示，完整统计与拟合不采样，但不能保留所有局部形态。超长标题、图例和标签仍需检查导出排版。
- 用户账户产品功能、订阅、付费、批量报告、云端项目保存尚未实现。管理员ChatGPT登录不是面向所有用户的账户系统。反馈URL尚未由管理员配置，因此反馈页面只说明配置入口，不编造联系方式。
- optional Python服务未公网部署；主站不依赖它。AI日预算按请求次数/输出token控制，不是货币硬上限；未来启用前还需服务商消费上限。实例并发限制不跨所有Worker隔离实例。
