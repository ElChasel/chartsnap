## 数值独立核对

- `y = 2x + 3` 线性答案与低阶二次多项式已知答案。
- 样本标准差使用 n−1，与独立手算核对。
- 收益率与 ln(1.1)、ln(0.9) 核对，零/负价格条件拒绝。
- 前端 QR 二次回归预测与 NumPy Polynomial.fit 比较；PCHIP 全曲线与 SciPy PchipInterpolator 比较，最大绝对偏差 < 1e−12。
- R² 在常量 Y 时为空；插值和平滑不显示回归 R²。

## 性能（实测，不作 SLA）

| 场景 | 开发服务器首轮 | 本地更新版 | 公网初始版 | 公网最终版 |

| 10,000 行真实 XLSX，上传至 SVG 可见 | 1046 ms | 1042 ms | 2389 ms | 1069 ms |
| 100,000 行 CSV，上传至 SVG 可见 | 2757 ms | 1781 ms | 1848 ms | 2828 ms |

单次暖浏览器结果，包含解析、Worker 数据传递、字段识别、映射和首次绘图；公网大文件仍在本地计算。不同运行的负载和缓存不同，不把差异解释为稳定的性能提升。没有百万行基准或移动低端机达标声明。
