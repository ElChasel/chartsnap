# 架构

此文保留3.0核心说明。4.0线上完整架构以 [V4_ARCHITECTURE.md](V4_ARCHITECTURE.md) 为准；发布方法见 [DEPLOYMENT.md](DEPLOYMENT.md)。

- React 19 / Vite：浅色首页、三栏工作台与响应式移动布局。
- Apache ECharts 6：SVG 交互预览，离屏 Canvas 高清 PNG 导出、SVG 导出。
- `src/engine.js`：独立纯函数数值模块。Welford 样本统计、QR 低阶回归、PCHIP、模型注册表、公式注册表、计划白名单验证。
- `src/worker.js`：独立 Worker 解析 XLSX/CSV，维护原始工作簿和派生数据集，执行变换、拟合与模型比较。解析结果在内存缓存；切换图表不重新解析。
- `src/chart.js`：字段映射、类别求和、直方图、箱线图、坐标轴和极值包络降采样。完整统计和拟合不使用展示采样。
- FastAPI / NumPy / SciPy：独立可选服务，提供 `/health`、`/compute`、`/plan`、`/capabilities`。核心网站不依赖它。
- `render.yaml`：可重复部署的 Python 服务定义。生产使用单 worker，限流与请求预算当前为进程内。

## 信任边界

默认不上传表格。AI 调用须用户在每次调用前同意，只发字段 schema 和统计摘要。前后端都校验计划，后端额外要求 Y 为数值列。模型不执行生成代码。公式和模型只能从注册表选择。没有使用 eval。

上传输入限制为 40 MB。XLSX 检查 ZIP 签名及中央目录，限制累计解压声明大小 200 MB、单条目 100 MB、压缩比 1000、条目数 10,000；拒绝 ZIP64，不执行宏。CSV 严格校验编码和列数。ZIP 目录检查是风险缓解，不能当作对恶意不一致 ZIP 元数据的完整沙箱。可取消 Worker 释放处理线程。XLSX/CSV 超过 1,000,000 行明确拒绝，不静默截断。

后端请求流最大 512 KB，数值 API 最多 10,000 点；调用有时限、CORS、严格 Pydantic 校验、安全头，不记录访问数据。AI 20 秒调用超时、1200 输出 token 上限、每日请求次数预算。生产多副本应迁移限流/预算到 Redis，并设置模型服务商消费上限。

## 计算约定

样本标准差使用 n−1；首行是字段名；全空行忽略。ISO 日期按 UTC，非 ISO 日期必须选择格式。基础公式按文件行顺序；不猜测时间频率或自动排序金融计算。折线图按 X 排序，重复 X 不自动合并；类别图明确提示求和。回归方程使用中心化 z 坐标并展示中心与尺度。候选线性/二次模型比较使用五折连续区块验证，不能当作预测回测。
