# 611 Studio 运营后台

## 进入与授权

公开网址后加 `/admin`。使用站点所有者对应的 ChatGPT 账号顶层登录，服务器按 ADMIN_EMAILS 允许列表校验。没有静态密码、前端管理员开关或任何匿名管理API。变更管理员需通过 Sites 的服务端环境配置更新白名单并重新部署；不要把邮箱白名单当作登录机制本身。

本地开发通过官方 Sites 模拟身份 seedy@sites.test；该模拟仅限loopback开发模式，不会发布到生产。真实平台账号登录在上线后需要管理员本人完成，代理不能冒充管理员登录。

## 指标和口径

- Today Visitors：所选时区今天产生已同意事件的去重浏览器标识。
- Live Active Sessions：当前最近5分钟有操作或可见页面心跳的会话；不是今日访客数，不表示严格网络连接人数。可见页面每60秒心跳。
- PV/UV/会话：所选范围内的事件、随机标识和30分钟签名会话估计。换设备、清除存储、拦截或拒绝同意影响覆盖。
- Chart Generations：成功提交ECharts图表的事件；类型/映射/数据版本/模型变化触发一次，颜色等样式重绘不重复计为新图。
- Successful Exports：浏览器实际生成PNG/SVG并发起下载；不能证明最终写入用户磁盘。
- Export Conversion：发生成功导出的会话 / 全部被统计会话，不用导出次数除以会话，防止超过100%。
- Average Processing Time：完成的解析、绘图、公式、拟合处理事件平均毫秒，不等同整站网络延迟。
- System Error Rate：processing_error / 被统计的处理终态事件；不代表基础设施全部HTTP请求错误率。
- 漏斗：按同一会话中的事件先后顺序，访问→打开Studio→上传成功→生成图表→导出。缺少前序事件时不补造。

支持最近1小时、今天、昨天、7天、30天与最多90天自定义范围，小时/天/周趋势。默认Asia/Shanghai，可选其他时区，按时区日历处理含DST的日期边界。后台15秒自动刷新，可手动刷新；异常时展示最近一次成功数据与时间，不用模拟值填补。

渠道：Direct、Xiaohongshu、WeChat、Search Engines、Other Referrals、Campaign UTM。来源不明确时不推断。推广链接：`/?utm_source=xiaohongshu&utm_medium=social&utm_campaign=launch`。会话建立时记录渠道，活动标识只接受有限字符，不保存完整URL或Referrer路径。

国家/地区来自托管平台粗粒度cf元数据；不可得时Unknown。设备、系统、浏览器为粗分类，不储存完整User-Agent、IP或精确位置；不推断年龄、性别、职业、收入。

## 数据真实性与边界

数据库创建后的首次已同意事件是采集起始，不能恢复升级前访客历史。上线验收的实际浏览器操作也会产生事件，不能把这些验收流量说成自然增长。按需保留最长90天，在写入时清理旧记录；没有新事件时旧记录不会由独立定时任务清理。

默认每日20,000事件、每会话每分钟120条、单批20条、后台最多查询50,000事件；达到上限会明确标记部分数据或拒绝写入，不宣称无限容量。额度限制为应用保护，不是托管服务的货币消费硬上限。多个并发请求的容量检查不是全局严格计数，可能小幅超过事件阈值。

统计只覆盖已同意且未被拦截的流量；不采集完整文件名、字段、表格数据、AI问题原文、金融信息或结果。没有录屏和热力图，未配置第三方分析平台，也未同步原生Sites Analytics。当前不提供可靠抗机器人识别或跨设备用户归并。
