# AI 接入状态与执行方式

用户明确选择“暂不授权付费调用，先完成接入与降级”。因此本次生产 `AI_BILLING_AUTHORIZED=false`，没有配置或调用真实模型密钥，也没有通过ChatGPT订阅冒充免费API。工作台和首页显示未启用状态；接口直接503，不发送模型请求。

首页 Upload & Visualize / Analyze with AI 双入口，带五个示例问题和输入框；工作台顶部Ask ChartSnap始终容易发现。AI关闭时仍能在专业分析使用免费确定性计算，没有假聊天响应。

## 已实现流水线

用户问题 → 明确授权传输问题、字段与统计摘要（不含原始行）→ 服务器严格Schema调用 → 服务端校验实际数值字段、公式/模型白名单、假设与待确认项 → 用户确认 → 注册函数在浏览器Worker执行 → 图表/计算结果/公式/残差与记录。界面把“分析建议，尚未执行”、假设、待确认信息与已计算事实分开。

真实调用默认兼容OpenAI Chat Completions JSON Schema strict输出；配置的服务商必须实际支持该格式。文档依据：https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat 。没有任意代码执行或eval。

公式：差分、百分比变化/简单收益、对数收益、累计和、移动平均、样本标准差、Min–Max、Z-Score、累计收益、年化波动、历史最大回撤、CAGR。模型：线性、二次多项式、指数（对数线性）、分段线性插值、PCHIP、移动平均平滑。未注册的用户自定义公式需求只能返回缺失信息/建议，不能凭空执行。

金融计算必须确认口径和行顺序。年化期数、CAGR跨越年数不自动猜测。若AI计划包含未决关键问题，不能一键执行，需用户明确条件；当前专业参数通过本地分析面板输入。

## 未来启用（尚未授权）

先由用户确认服务商费用和可接受的预算，再通过受支持的服务端Secrets流程设置 OPENAI_API_KEY、OPENAI_MODEL、可选OPENAI_BASE_URL，并将AI_BILLING_AUTHORIZED显式设为true。绝不可把密钥写入前端或公开网页。默认模型配置名gpt-4.1-mini只是服务端可修改默认值，不代表实际已经使用或该账号可用。

有日请求次数、token输出上限、超时、用户频率控制、缓存和失败降级；它们不替代服务商的货币消费上限。多实例并发不是全局信号量。模型异常不自动重复付费调用；用户可显式重试。

测试使用mock模型响应验证计划与实际计算连接、非法计划拒绝和超时，不把mock验收当作真实LLM质量验收。没有真实AI已上线的声明。
